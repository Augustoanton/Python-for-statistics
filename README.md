# Trabajo Práctico: Programacion Estadistica Avanzada

## Descripción

Este trabajo práctico está dividido en tres ejercicios:

1. **Ejercicio 1** — Generacion de datos para la comparacion de la robustez de la media Muestral y de la mediana ante la introduccion de diferentes niveles de contaminacion a la muestra. Se realizo el mismo procedimiento en el segundo inciso del ejercicio para la comparacion entre las regresiones generadas por OLS y el metodo de Least Absolute Deviations (LAD). 
2. **Ejercicio 2** — En este ejercicio se simulan datos con una estructura particular para demostrar que el sesgo por variables omitidas ante esta estructura no desaparece con el aumento en el tamaño de la muestra.
3. **Ejercicio 3** — Analisis comparativo de la evolucion del indice de esperanza de vida Argentino con respecto a ciertos grupos de referencia, como los paises de la OCDE y los paises latinoamericanos
                     Análisis comparativo del ingreso per cápita de Argentina respecto al resto de los países de América Latina, incluyendo identificación de períodos de atipicidad (desvío respecto a la media/mediana regional) y su vinculación con hechos históricos.
